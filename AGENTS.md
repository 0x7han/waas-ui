## Communication language (STRICT)

All persistent artifacts MUST be written in English. This covers commit messages,
branch names, issue titles/bodies/comments, PR titles/bodies/comments, docs
(`docs/`, `*.md`), code comments, and user-facing strings shipped by the library.
Indonesian is allowed only in live conversation with the maintainer — never in the
repo, the tracker, or the code. When translating an existing artifact, preserve its
meaning; do not add new decisions.
